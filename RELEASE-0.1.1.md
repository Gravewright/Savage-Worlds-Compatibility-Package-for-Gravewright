# Savage Worlds Compatibility Package for Gravewright — 0.1.1

All Savage Worlds functionality now ships in one system package. The system ZIP
contains sheets, item templates, settings, translations, card artwork and server
automation for effect, power and temporary-state clocks. There is no separate
Server Rules module to install or list in the Marketplace.

Requires Gravewright VTT 0.2.4 or newer and SDK 1.0.0. Install
`gravewright-savage-worlds-0.1.1.zip` under **Systems**, activate the bundled
server automation as host owner, and select version 0.1.1 for the table. The
managed Runner performs the required restart. Existing actor data, table settings,
decks, IDs and authored content remain in their original system namespace.
Activating this system automatically supersedes the legacy Server Rules
activation while retaining its installed archive for rollback.

The release contains no rulebook, proprietary catalogs or game content.
Original branding permissions, the unchanged Fan Product logo and the exact
Pinnacle notice are preserved. The ZIP includes its SHA-256 sidecar.

## Português (Brasil)

Todas as funções do Savage Worlds ficam em um único pacote de sistema: fichas,
itens, configurações, traduções, cartas e automações de servidor. Não há módulo
Server Rules separado para instalar ou listar no Marketplace.

Requer Gravewright VTT 0.2.4 ou posterior. Instale o ZIP em **Sistemas**, ative
as automações como proprietário do host e selecione a versão 0.1.1 na mesa.

criado pelo usuário permanecem no mesmo namespace.
