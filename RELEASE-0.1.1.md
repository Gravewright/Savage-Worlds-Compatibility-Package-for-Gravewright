# Savage Worlds Compatibility Package for Gravewright — 0.1.1

All Savage Worlds functionality ships in one browser system package for the
published Gravewright VTT **0.2.3**, using its existing SDK **1.0.0**. The ZIP
contains sheets, item templates, settings, translations, card artwork and
package-owned duration automation. It contains no Python app or separate module.

Install `gravewright-savage-worlds-0.1.1.zip` under **Systems** and select this
version for the table. The GM advances combat through the system tracker.
Operation plans and native document revisions preserve completed steps across
retries and reconnects; writes to different sheets remain recoverable steps,
not one shared database transaction. Automation does not run after all table
clients close. Existing actor data, table settings, decks and authored content
remain in their original system namespace.

For an older Server Rules installation, **Customize → About → Previous installation**
offers an owner-authorized deactivation with the host's existing restart flow.
Archive removal is a separate confirmation after reviewing affected tables.
Fresh installations have no companion or server-code activation to perform.

The release contains no rulebook, proprietary catalogs or game content.
The unchanged Fan Product logo and exact Pinnacle permission notice are preserved.
The ZIP has a SHA-256 sidecar. The VTT itself is unchanged.

## Português (Brasil)

Todas as funções do Savage Worlds ficam em um único pacote de sistema para o
navegador, compatível com o Gravewright VTT **0.2.3 já publicado** e SDK **1.0.0**:
fichas, modelos de itens, opções, traduções, cartas e automações de duração.
O ZIP não contém app Python nem módulo separado.

Instale em **Sistemas**, selecione a versão 0.1.1 para a mesa e use o tracker do
pacote como mestre. Planos persistidos e revisões nativas permitem retomar etapas
interrompidas sem repetir as já concluídas. Não há uma transação única entre
fichas nem execução depois que todos fecham a mesa. Os dados existentes permanecem
no namespace original.

Uma instalação anterior do Server Rules pode ser revisada em **Personalizar →
Sobre → Instalação anterior**. O proprietário autoriza a desativação e o reinício
nativo; remover o arquivo exige outra confirmação após ver as mesas afetadas.
Uma instalação nova usa somente o pacote do sistema. O VTT permanece inalterado.
