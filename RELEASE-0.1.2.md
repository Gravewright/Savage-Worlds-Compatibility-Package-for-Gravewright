# Savage Worlds Compatibility Package for Gravewright — 0.1.2

Character and NPC sheets, all thirteen item types, roll windows and empty
collections use less vertical space. Spacing and corner tokens are defined in
the package; interface text remains at least 12px on the published Gravewright
VTT **0.2.3**, SDK **1.0.0**. Headers emphasize document names, attributes avoid
nested frames, and Wound/Fatigue controls display their base penalties.
The action bar prioritizes trait tests and damage; the remaining actions open
through the existing native **Actions** modal.

Skills, inventory, features, powers and library rows sort alphabetically by
their displayed names in the active language. Named skill, pool, modifier and
power choices retain their selections and focus. Sorting does not rearrange
saved collections. Each skill's linked attribute selector preserves its own die
and modifier; later rolls use the current link for applicable effects and
penalties. Narrow skill rows group labelled controls below the name.

Item headers, detail groups, descriptions and notes fit their content. Reading
previews avoid repeating header facts. Long content stays scrollable, and
standalone editors, owned copies and read-only views retain their fields,
permissions and saving behavior. Native movement, resizing, keyboard focus,
Escape and closing remain available. Use **Reset window layout (↺)** in a
title bar to replace an older saved layout with the compact default.

## Install and compatibility

Install **Savage Worlds Compatibility Package for Gravewright 0.1.2** from the
signed Marketplace under **Systems**, or download
`gravewright-savage-worlds-0.1.2.zip` and its SHA-256 sidecar from the
[source release](https://github.com/Gravewright/Savage-Worlds-Compatibility-Package-for-Gravewright/releases/tag/v0.1.2).
Select that exact version in the table's **Settings → Extensions**.

Unpublished local review builds are consolidated into this release. If another
local 0.1.2 is already installed, first switch affected tables to another
installed version, remove that local build with native package management,
then install the public 0.1.2. The host rejects different bytes for an installed
ID/version pair. Higher local review versions require manual selection of
0.1.2 rather than an automatic update.

One browser system package contains sheets, item templates, settings,
translations, original card artwork and duration automation. It requires no
host upgrade or Server Rules companion. English remains the default; the
official Translator provides English, Brazilian Portuguese and Spanish through
the native account language preference. Existing campaign data, settings,
decks and authored content remain in their system namespace.

The native item directory and compendium browser belong to Gravewright; their
separate host interface changes are not included in this ZIP. No rulebook,
PDF, proprietary catalog or compendium is distributed. Original code and card
art remain MIT; Pinnacle names, trademarks and the unchanged Fan Product logo
remain outside that license. The exact permission notice is preserved.

## Português (Brasil)

Fichas de personagens e NPCs, os treze tipos de item, janelas de rolagem e listas
vazias ocupam menos espaço vertical. Os tokens de espaçamento e cantos ficam
no pacote; o texto da interface tem pelo menos 12px no Gravewright VTT
**0.2.3 já publicado**, SDK **1.0.0**. Os cabeçalhos destacam o nome, atributos
dispensam molduras internas e os controles de Ferimentos/Fadiga exibem suas
penalidades básicas. A barra destaca testes e dano; as outras opções ficam no
modal nativo **Ações**.

Perícias, inventário, características, poderes e biblioteca usam ordem
alfabética pelo nome exibido no idioma ativo. Seletores de perícias, reservas,
modificadores e poderes mantêm seleções e foco. A apresentação não altera a
ordem das coleções salvas. O seletor de atributo vinculado de cada perícia
preserva seu dado e modificador; as rolagens seguintes usam o vínculo atual
nos efeitos e penalidades aplicáveis. Linhas estreitas agrupam os controles
rotulados abaixo do nome.

Cabeçalhos de item, grupos de detalhes, descrições e anotações acompanham o
conteúdo. Prévias de leitura evitam repetir os fatos do cabeçalho. Conteúdo
longo continua com rolagem; editores independentes, cópias na ficha e telas de
leitura preservam campos, permissões e salvamento. Movimento, redimensionamento,
foco pelo teclado, Escape e fechamento nativos continuam disponíveis. Use
**Redefinir layout da janela (↺)** na barra de título para substituir um
tamanho antigo salvo pelo padrão compacto.

Instale **Savage Worlds Compatibility Package for Gravewright 0.1.2** pelo
Marketplace assinado em **Sistemas**, ou pelo ZIP e checksum da release, e
selecione essa versão em **Configurações → Extensões** da mesa. Os builds
locais de revisão foram reunidos nesta versão. Se outra 0.1.2 local já estiver
instalada, selecione outra versão instalada nas mesas afetadas, remova aquele
build pelo gerenciador nativo e instale a 0.1.2 pública. O host não sobrescreve
o mesmo ID/versão com bytes diferentes. Builds locais com numeração maior
exigem selecionar a 0.1.2 manualmente.

O único pacote de sistema para navegador reúne fichas, modelos de itens,
opções, traduções, cartas originais e automações de duração. Não exige atualização
do VTT nem Server Rules separado. Inglês continua como padrão; o Translator
oficial permite escolher inglês, português brasileiro e espanhol na conta.
Campanhas, configurações, baralhos e conteúdo autoral permanecem no namespace
do sistema.

O diretório nativo de itens e o navegador de compêndios pertencem ao VTT; as
mudanças separadas dessas interfaces não integram este ZIP. Nenhum livro, PDF,
catálogo proprietário ou compêndio é distribuído. Código e cartas originais
permanecem sob MIT; nomes, marcas e logo Fan Product inalterado da Pinnacle
ficam fora dessa licença. O aviso literal de permissão é preservado.
